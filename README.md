# wehoop-data

> [!WARNING]
> **ARCHIVE — this repository is not maintained.**
>
> This repo is an archive of the legacy combined R producer for women's college
> basketball and WNBA data. Data here may be stale. New data and active
> development live in the successor repos:
>
> - [sportsdataverse/wehoop-wbb-data](https://github.com/sportsdataverse/wehoop-wbb-data) — women's college basketball (ESPN)
> - [sportsdataverse/wehoop-wnba-data](https://github.com/sportsdataverse/wehoop-wnba-data) — WNBA (ESPN)
> - [sportsdataverse/wehoop-wnba-stats-data](https://github.com/sportsdataverse/wehoop-wnba-stats-data) — WNBA (WNBA Stats API)
>
> Published datasets are distributed through the
> [sportsdataverse-data](https://github.com/sportsdataverse/sportsdataverse-data)
> release ecosystem, consumed by the [wehoop](https://github.com/sportsdataverse/wehoop)
> R package and [sportsdataverse-py](https://github.com/sportsdataverse/sportsdataverse-py).
